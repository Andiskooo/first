# ECOTEK

Marketing site for ECOTEK (ecotek-ks.com): products, installations, articles, and support.

## Hydraulic studio

`/studio` is an in-browser hydronic schematic. Visitors place a heat pump, a buffer tank, pumps, and heat users, connect supply and return, and run a simple water-temperature model. Nothing is stored.

See [docs/studio.md](docs/studio.md) for how to add a component and how to swap the heat pump image.
